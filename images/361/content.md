## 📖 Phrasal Verb Note
**1. 기본 의미 vs 관용적 의미**
- 기본 의미: 글자 그대로 종이나 화면에 적다
- 관용적 의미: 나중에 잊지 않으려고 메모해두다 (기억 보조 수단으로서의 '적기')
**2. 문형(분리형 여부)**
- write down은 분리형(separable) 구동사다.
- 목적어가 명사면: write down the number / write the number down (둘 다 가능)
- 목적어가 대명사면: write it down (반드시 분리해야 함, write down it은 불가능)
**3. 언제 쓰나요(뉘앙스·격식도)**
- 캐주얼한 일상 대화, 수업, 메모 상황 어디서든 무난하게 쓰이는 중립적 표현
- 격식 있는 자리에서도 사용 가능하지만, 정식 보고서 작성에는 write up이 더 어울림
**4. 대표 예문**
- Please write down the homework before you forget it.
- I always write down my dreams right after I wake up.
**5. 헷갈리는 유사 구동사**
- write up: 메모가 아니라 정리된 글/보고서로 완성하다
- take down: (받아쓰기처럼) 말하는 것을 그대로 적다는 의미로 write down과 유사하지만, 주로 공식적인 기록·진술을 받아 적을 때 씀
- jot down: write down보다 훨씬 빠르고 간단하게 휘갈겨 적는다는 뉘앙스
**6. 시험/회화 포인트**
- 대명사 목적어일 때 분리 필수라는 점이 어법 문제로 자주 나옴 (write down it → 오답)
- 회화에서는 "Let me write that down"이 관용구처럼 자주 쓰임

1. Write down it on the paper.
2. I wrote down carefully the number.
3. Write down them in your notebook.
**C. Make your own sentence**
- write down을 사용해서, 오늘 하루 중 무언가를 잊지 않으려고 적어둔 상황을 한 문장으로 써보세요.

## ✅ Answer Key
**A.**
1. a) write down (write up은 완성된 문서를 작성한다는 뜻이라 여기선 어색함)
2. b) writes down
3. a) write down
**B.**
1. → Write it down on the paper. (대명사 목적어는 반드시 분리해서 사이에 넣어야 함)
2. → I wrote the number down carefully. / I wrote down the number carefully. (부사 위치 조정, 명사 목적어는 둘 다 가능)
3. → Write them down in your notebook. (대명사 목적어이므로 반드시 분리)
**C.**
- 예시: I wrote down her phone number so I wouldn't lose it.
