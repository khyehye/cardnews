## 📖 Grammar Note

### 1. 핵심 개념

주어-동사 수 일치는 문장의 주어가 단수인지 복수인지에 따라 동사의 형태를 결정하는 규칙이다. 현재시제에서는 특히 3인칭 단수 주어일 때만 동사에 -s/-es가 붙는다는 점이 핵심이며, 이 규칙은 문장의 정확성을 판단하는 기본 잣대가 된다.

### 2. 형태 / 공식

- 3인칭 단수 주어(He/She/It, 단수명사) + 동사원형-s/-es
- I/You/We/They, 복수명사 + 동사원형
- each, every, one of + 복수명사 → 단수 동사
- a number of, A and B → 복수 동사
- the number of → 단수 동사

### 3. 언제 쓰나요?

현재시제 문장을 만들 때마다 이 규칙이 적용되며, 특히 문장의 주어 자리에 each, every, one of, a number of 같은 표현이 올 때 동사 선택을 결정짓는다. 서술형이나 문법 오류 찾기 문제에서 자주 확인하는 포인트다.

### 4. 대표 예문

- **Everybody** in the class **enjoys** the field trip. (모두가 소풍을 즐긴다)
- **A number of** questions **remain** unanswered. (많은 질문들이 답이 없는 채로 남아있다)
- **Neither of** the answers **is** correct. (어느 답도 맞지 않다)
- **The news** **was** shocking to everyone. (그 소식은 모두에게 충격적이었다)
- **Two-thirds of the students** **are** absent today. (학생의 3분의 2가 오늘 결석이다)

### 5. 자주 하는 실수

- X: Each of the boys **are** tall. → O: Each of the boys **is** tall. (each는 단수 취급)
- X: The number of visitors **are** small. → O: The number of visitors **is** small. (the number of는 단수)
- X: A number of people **is** waiting. → O: A number of people **are** waiting. (a number of는 복수)

### 6. 시험 포인트

each/every, one of, the number of처럼 겉모습은 복수 같지만 단수로 취급되는 표현과, a number of, A and B처럼 복수로 취급되는 표현을 구분하는 문제가 자주 출제된다. 분수나 퍼센트 주어(예: two-thirds of)는 뒤에 오는 명사의 수에 따라 동사가 달라진다는 점도 함께 출제되는 편이다.

## ✏️ Practice

### A. Choose the correct answer

1. Every player on the team ___ (know/knows) the rules.
2. A number of students ___ (was/were) late for class.
3. Neither of the choices ___ (seem/seems) right.
4. The number of accidents ___ (has/have) decreased this year.
5. One of my friends ___ (live/lives) in Busan.

### B. Fix the mistake

1. Each of the rooms have a window. →
2. The number of applicants were higher than expected. →
3. A number of solutions was proposed. →

### C. Make your own sentence

1. "each of + 복수명사"를 사용해서 문장을 하나 만들어보세요.
2. "a number of"와 "the number of"를 각각 사용한 문장을 하나씩 만들어보세요.

## ✅ Answer Key

A. 1. knows (Every+단수 취급) / 2. were (a number of=복수) / 3. seems (neither=단수) / 4. has (the number of=단수) / 5. lives (one of+복수명사=단수)
B. 1. Each of the rooms **has** a window. / 2. The number of applicants **was** higher than expected. / 3. A number of solutions **were** proposed.
C. 1. (예시) Each of the students has his own locker. / 2. (예시) A number of people are joining the event, but the number of seats is limited.
