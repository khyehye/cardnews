## 📖 Exam Trap Note
**1. 함정 포인트**<br>should have p.p.와 must have p.p.는 둘 다 "조동사 + have + p.p." 형태라 겉모습이 똑같아 보이지만, should have는 '후회/의무 불이행', must have는 '강한 추측'으로 의미가 완전히 다르다. 수능/모의고사에서는 이 둘을 문맥 없이 형태만으로 헷갈리게 만들거나, have 뒤 동사 형태를 원형·3인칭 단수 등으로 바꿔 오류를 심는다.
**2. 판별 공식/체크리스트**
- have 바로 뒤 동사 → 무조건 과거분사(p.p.)인가? (go(X) → gone(O))
- 문맥이 "이미 벌어진 일에 대한 후회/아쉬움"인가 → should have
- 문맥이 "과거 일에 대한 화자의 강한 확신/추측"인가 → must have
- not의 위치는 should 바로 뒤(should not have p.p.)인가?
**3. 오답 예문 vs 정답 예문**
- (X) He should have leave earlier. → (O) He should have left earlier.
- (X) She must has arrived by now. → (O) She must have arrived by now.
- (X) You should must have told me. (조동사 두 개 연속 사용 불가) → (O) You should have told me.
**4. 기출 변형 패턴**
- 밑줄 친 동사 형태가 p.p.로 올바른지 묻는 유형
- must have / should have 중 문맥상 알맞은 것을 고르는 유형
- should have p.p. 부정형에서 not 위치를 어긋나게 배치해 어색하게 만드는 유형
**5. 실전 풀이 순서**<br>① have 뒤 동사가 p.p. 형태인지 먼저 확인 → ② 조동사가 should인지 must인지 보고 문맥(후회 vs 추측) 판단 → ③ not이 들어간 경우 위치 확인 → ④ 최종적으로 의미가 문장 전체 흐름과 맞는지 재검토

## ✏️ Practice
**A. 어법상 틀린 것 고르기**
1. I should have (①called) her yesterday, but I (②forgot).
2. He (①must have) (②study) all night — he looks exhausted.
3. They (①should not have) (②went) without telling us.
**B. Fix the mistake (틀린 이유 서술)**
1. She should have tell him the truth.
2. You must have forget your umbrella — it's still raining outside.
3. We should have not left the door unlocked.
**C. 유사 유형 만들어보기**<br>주어진 상황을 보고 should have p.p. 또는 must have p.p.를 활용한 문장을 각각 하나씩 만들어보세요.
- 상황1: 어제 시험을 망쳤고, 공부를 더 했어야 했다고 후회하는 상황
- 상황2: 친구가 갑자기 연락이 안 되는데, 아마 폰이 꺼진 것 같다고 추측하는 상황

## ✅ Answer Key
**A.**
1. 오류 없음 — should have called, forgot 모두 올바른 형태다. 이렇게 "틀린 곳이 없는" 선택지도 나올 수 있다는 데 유의해야 한다.
2. ②study → must have studied — have 뒤에는 반드시 과거분사가 와야 하므로 원형 study는 오류.
3. ②went → should not have gone — have 뒤에는 과거분사 gone이 와야 하며, not의 위치(should 바로 뒤)는 이미 올바르다.
**B.**
1. → should have told (tell을 told/p.p.로 수정) — have 뒤엔 과거분사만 가능
2. → must have forgotten (forget을 forgotten으로 수정) — 추측의 must have도 have+p.p. 형태 동일 적용
3. → should not have left (not의 위치를 should 바로 뒤로 이동) — should not have p.p. 어순 고정
**C.** (예시 답안)
- 상황1: I should have studied harder for the test.
- 상황2: She must have run out of battery — she's not answering.
