## 📖 Grammar Note

### 1. 핵심 개념

가정법은 실제와 다른 상황을 "만약에"로 가정해서 말하는 문법이다. 핵심은 if절의 동사 시제가 하나씩 뒤로 밀린다는 것 — 현재 사실의 반대는 과거형으로, 과거 사실의 반대는 had p.p.로 표현한다. 이 회차는 49·72·73회차에서 배운 세 가지 가정법(현재/과거/과거완료)과 혼합가정법을 실전 문제로 한 번에 복습한다.

### 2. 형태 / 공식

- 가정법 현재: If + S + 현재동사, S + will/can + 동사원형
- 가정법 과거: If + S + 과거동사(were), S + would/could/might + 동사원형
- 가정법 과거완료: If + S + had + p.p., S + would/could/might + have + p.p.
- 혼합가정법: If + S + had + p.p.(과거 조건), S + would + 동사원형(현재 결과)

### 3. 언제 쓰나요?

실현 가능성이 있는 미래의 조건에는 가정법 현재를, 지금 현실과 다른 상상에는 가정법 과거를 쓴다. 이미 끝난 과거의 일을 되돌아보며 "그때 이랬다면"이라고 상상할 때는 가정법 과거완료를, 과거의 조건이 지금까지 영향을 미치는 경우엔 혼합가정법을 쓴다.

### 4. 대표 예문

- If you heat ice, it melts. (가정법 현재 — 조건문에 가까운 일반적 사실)
- If I had wings, I would fly over the mountains. (가정법 과거 — 현재 불가능한 상상)
- If he had left earlier, he would not have missed the train. (가정법 과거완료 — 과거의 다른 결과 상상)
- If I hadn't lost my phone yesterday, I would have your number now. (혼합가정법 — 어제의 실수가 지금까지 영향)
- Were I in charge, I would change the schedule. (가정법 과거의 도치형 — if 생략)

### 5. 자주 하는 실수

- X: If I will have time, I will call you. → O: If I have time, I will call you. (if절엔 미래시제 대신 현재시제)
- X: If I was you, I would rest. → O: If I were you, I would rest. (가정법 과거의 be동사는 인칭 상관없이 were)
- X: If she had study harder, she would pass. → O: If she had studied harder, she would have passed. (주절도 have p.p.로 맞춰야 함)

### 6. 시험 포인트

서술형에서는 주어진 두 문장을 가정법으로 바꾸는 문제가 자주 나오며, if절과 주절의 시제를 짝 맞추는지가 채점 포인트다. 객관식에서는 were it not for, had it not been for 같은 if 생략 도치구문과, wish/as if + 가정법 과거 패턴이 자주 출제된다.

## ✏️ Practice

### A. Choose the correct answer

1. If I ___ more time, I would learn Japanese. (a) have (b) had (c) will have
2. If they ___ harder last year, they would have won the contest. (a) practice (b) practiced (c) had practiced
3. ___ it not for the rain, we would go hiking today. (a) Were (b) Had (c) If
4. She wishes she ___ speak French fluently. (a) can (b) could (c) will can

### B. Fix the mistake

1. If I was a scientist, I would invent a time machine.
2. If he has arrived on time, he would not have missed the meeting.

### C. Make your own sentence

1. 지금 원어민처럼 영어를 할 수 있다면 무엇을 하고 싶은지 가정법 과거로 문장을 만들어 보세요.
2. 어제 늦잠을 자지 않았다면 오늘 무엇이 달라졌을지 혼합가정법으로 문장을 만들어 보세요.

## ✅ Answer Key

A. 1. (b) had — 가정법 과거는 if절에 과거동사 / 2. (c) had practiced — 가정법 과거완료 / 3. (a) Were — if it were not for의 도치형 / 4. (b) could — wish 뒤엔 가정법 과거(could)
B. 1. If I were a scientist, I would invent a time machine. / 2. If he had arrived on time, he would not have missed the meeting.
C. (예시) 1. If I could speak English like a native speaker, I would travel around the world alone. / 2. If I hadn't stayed up late last night, I would feel fresh today.
