## 📖 Confusion Note
**1. 각 단어 기본 뜻**
- some: 대략적인 수·양, "약간의, 몇몇의"
- any: "전혀, 조금이라도" — 부정·의문의 뉘앙스
**2. 구별 포인트 (판단기준 하나로 요약)**<br>문장이 긍정문인지, 부정문/의문문인지를 먼저 확인한다. 긍정 평서문 → some, 부정문·일반의문문 → any.
**3. 대표 예문 비교**
- I have some apples. (긍정)
- I don't have any apples. (부정)
- Do you have any apples? (의문)
**4. 자주 하는 실수 (X→O)**
- X: I don't have some money. → O: I don't have any money.
- X: Do you have some questions? (일반적인 질문) → O: Do you have any questions?
- 예외 주의: Would you like some coffee? (권유문은 some 유지, any로 안 바꿈)
**5. 시험 포인트**
- 부정어(never, hardly, without 등) 뒤에는 any가 온다는 것을 반드시 체크.
- 권유·부탁의 의문문(Would you like ~?, Can I have ~?)은 some을 쓰는 예외 유형으로 자주 출제됨.

## ✏️ Practice
**A. Choose the correct word**
1. I don't need ___ help right now. (some / any)
2. There were ___ people waiting outside. (some / any)
3. Is there ___ chance of rain today? (some / any)
**B. Fix the mistake**
1. She doesn't have some free time these days.
2. Do you want some water? I'm really thirsty, is that anything left?
3. He never eats some vegetables.
**C. Make your own sentence (두 단어 각각 활용)**
1. some을 사용한 긍정문 한 문장 만들기
2. any를 사용한 부정문 한 문장 만들기

## ✅ Answer Key
**A.** 1. any (부정문) / 2. some (긍정문) / 3. any (의문문)<br>**B.** 1. → She doesn't have any free time these days. / 2. → Do you want some water? (권유문 그대로 유지, 뒤 문장은 별개 오류이므로 수정 불필요) / 3. → He never eats any vegetables.<br>**C.** 예시 답안: I bought some cookies for the party. / I can't find any pens in my bag.
