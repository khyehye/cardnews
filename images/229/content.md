## 📖 Exam Trap Note
**1. 함정 포인트**<br>학생들은 "의문문 = 무조건 any"라고 단순 암기해서, 권유·요청을 나타내는 의문문(Would you like some...?, Can I have some...?)에서도 any를 쓰는 실수를 한다.
**2. 판별 공식/체크리스트**
- 문장이 긍정 서술문인가? → some
- 문장이 부정문 또는 정보를 묻는 일반 의문문인가? → any
- 문장이 상대에게 무언가를 "권하거나 요청"하는가? → some (예외)
- 문장이 if로 시작하는 조건절인가? → any (예외)
**3. 오답 예문 vs 정답 예문**
- ❌ Do you have some questions? → ⭕ Do you have any questions?
- ❌ Would you like any coffee? → ⭕ Would you like some coffee?
- ❌ If you need some help, call me. → ⭕ If you need any help, call me.
**4. 기출 변형 패턴**
- Is there ___ + 불가산명사? (any)
- Would/Could you like/care for ___ + 명사? (some)
- If ___ + 절, ... (any)
- There isn't/aren't ___ + 명사 (any)
**5. 실전 풀이 순서**<br>① 문장이 긍정/부정/의문 중 무엇인지 먼저 확인 → ② 의문문이면 "권유·요청"인지 다시 확인 →<br>③ if절인지 확인 → ④ 최종적으로 some/any 결정

## ✏️ Practice
**A. 어법상 틀린 것 고르기**
1. She doesn't have ① some ② any brothers or sisters.
2. Could I have ① some ② any more time to finish this?
3. If there are ① some ② any problems, let the teacher know.
**B. Fix the mistake**
1. Do you need some money for the trip? → (수정: ______)
2. I don't want some vegetables in my soup. → (수정: ______)
3. Would you like any dessert after dinner? → (수정: ______)
**C. 유사 유형 만들어보기**<br>학생이 직접 "권유 의문문 + some" 또는 "if절 + any" 패턴을 활용한 새 예문을 1개씩 만들어보기.

## ✅ Answer Key
**A.**
1. ② any (부정문이므로 any)
2. ① some (권유·요청 의문문이므로 some) — 함정: Could I have ~?는 요청 표현
3. ② any (if절이므로 any) — 함정: some처럼 보이지만 조건절 규칙 적용
**B.**
1. Do you need any money for the trip? (일반 의문문 → any)
2. I don't want any vegetables in my soup. (부정문 → any)
3. Would you like some dessert after dinner? (권유 의문문 → some, 원문이 오답)
**C.** (학생 자유 작성 — 권유 의문문/if절 패턴 포함 여부로 평가)
