## 📖 Grammar Note

### 1. 핵심 개념

some과 any는 둘 다 "몇몇의, 약간의"라는 뜻이지만, 어떤 종류의 문장에서 쓰이는지가 다릅니다. 문장이 긍정문인지, 의문문·부정문인지를 먼저 확인하는 습관이 중요해요. 다만 상대방이 Yes라고 답할 것 같은 권유나 제안의 의문문에서는 예외적으로 some을 씁니다.

### 2. 형태 / 공식

- 긍정문: some + 명사 (I have some cookies.)
- 의문문: any + 명사 (Do you have any cookies?)
- 부정문: not ~ any + 명사 (I don't have any cookies.)
- 예외 (권유·제안 의문문): some + 명사 (Would you like some cookies?)
- some/any 뒤에는 셀 수 있는 명사(복수형)와 셀 수 없는 명사 둘 다 올 수 있음

### 3. 언제 쓰나요?

사실을 있는 그대로 말하는 긍정문에는 some을, 무언가 있는지 확인하거나 없다고 말할 때는 any를 씁니다. 하지만 대화에서 상대방에게 무언가를 권하거나 부탁할 때는 대답이 긍정적일 거라 기대하기 때문에 some을 사용해요. 이 예외는 실생활 대화문에서 자주 등장합니다.

### 4. 대표 예문

- She bought some flowers for her mom. (그녀는 엄마를 위해 꽃을 좀 샀다.)
- Are there any pencils in the box? (상자 안에 연필이 좀 있나요?)
- We don't have any homework today. (오늘은 숙제가 하나도 없다.)
- Can I have some more juice? (주스 좀 더 마셔도 될까요?)
- He didn't ask any questions in class. (그는 수업 시간에 질문을 하나도 하지 않았다.)

### 5. 자주 하는 실수

- X: Do you have some time? → O: Do you have any time? (단순 질문은 any)
- X: I have any money. → O: I have some money. (긍정문은 some)
- X: Would you like any dessert? → O: Would you like some dessert? (권유는 some)

### 6. 시험 포인트

객관식에서는 문장이 긍정/의문/부정 중 어느 형태인지 구별하는 문제가 자주 나옵니다. 서술형에서는 "Would you like ~?", "Can I have ~?" 같은 권유·요청 문형에 some을 쓰는 예외 규칙을 아는지 확인하는 문제가 자주 출제돼요.

3. Is there (some / any) sugar left?

5. We didn't see (some / any) animals at the zoo.

### B. Fix the mistake

1. Do you need some help right now? →
2. I don't have some free time today. →
3. Could I have any water, please? →

### C. Make your own sentence
