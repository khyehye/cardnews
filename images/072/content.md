## 📖 Grammar Note

### 1. 핵심 개념

가정법 과거완료는 과거의 사실과 반대되는 상황을 가정할 때 쓰는 표현이에요. If절에는 과거완료(had + p.p.), 주절에는 「조동사 과거형 + have + p.p.」를 써서, 실제로는 일어나지 않았던 일을 상상하며 후회나 아쉬움을 나타냅니다.

### 2. 형태 / 공식

- If + 주어 + had + p.p. ~, 주어 + would/could/might + have + p.p. ~
- 부정형: If + 주어 + had not + p.p. ~
- 도치형: Had + 주어 + p.p. ~ (If 생략, Had가 문두로 이동)

### 3. 언제 쓰나요?

과거에 이미 끝나버린 일을 두고 "그때 이랬더라면 저랬을 텐데"라며 후회하거나, 실제와 반대되는 과거 상황을 가정해서 결과를 추측할 때 사용해요. 시험 지문에서는 주로 후회·아쉬움을 드러내는 문맥에 자주 등장합니다.

### 4. 대표 예문

1. If I had left earlier, I wouldn't have missed the bus. — 더 일찍 나갔더라면 버스를 놓치지 않았을 텐데.
2. If they had booked the tickets earlier, they could have gotten better seats. — 표를 더 일찍 예매했더라면 더 좋은 자리를 얻을 수 있었을 텐데.
3. Had I known about the traffic, I would have taken another route. — 교통 정체를 알았더라면 다른 길로 갔을 텐데.
4. If he had apologized sooner, she might have forgiven him. — 그가 더 빨리 사과했더라면 그녀가 용서했을지도 몰라.
5. If it had not been for the storm, the flight would have arrived on time. — 폭풍우가 없었더라면 비행기가 제시간에 도착했을 텐데.

### 5. 자주 하는 실수

- X: If I would have studied, I would have passed. → O: If I had studied, I would have passed. (if절에 would have를 쓰지 않아요)
- X: If I had knew the answer... → O: If I had known the answer... (had 뒤에는 항상 과거분사)
- X: Had I know, I would have told you. → O: Had I known, I would have told you. (도치 후에도 p.p. 형태 유지)

### 6. 시험 포인트

서술형에서는 「If절 → Had 도치」 전환 문제가 자주 출제되고, 객관식에서는 if절과 주절의 시제를 혼동하게 만드는 오답(would have vs had, 과거완료 vs 단순과거)이 자주 나와요. "If it had not been for" 같은 관용 표현도 빈출이니 꼭 익혀두세요.

## ✏️ Practice

### A. Choose the correct answer

1. If she ___ harder, she would have won the contest. (a. studies / b. had studied / c. would study)
2. ___ I known you were coming, I would have cooked dinner. (a. If / b. Had / c. Have)
3. If we had left on time, we ___ the train. (a. wouldn't miss / b. wouldn't have missed / c. don't miss)
4. If it had not been for his advice, I ___ the wrong decision. (a. would make / b. would have made / c. make)

### B. Fix the mistake

1. If I would have known, I would have helped you.
2. If she has studied harder, she would have passed.
3. Had I knew about the meeting, I would have attended.

### C. Make your own sentence

1. 어제 늦잠을 자서 시험에 늦은 상황을 가정법 과거완료로 표현해 보세요.
2. 친구의 조언을 듣지 않아서 후회했던 과거의 일을 가정법 과거완료로 써 보세요.

## ✅ Answer Key

**A.** 1. b (if절엔 과거완료) / 2. b (Had 도치, If 생략) / 3. b (주절은 would have p.p.) / 4. b (관용표현 뒤 결과절은 would have p.p.)

**B.** 1. If I had known, I would have helped you. / 2. If she had studied harder, she would have passed. / 3. Had I known about the meeting, I would have attended.

**C.** (예시) 1. If I hadn't overslept, I wouldn't have been late for the exam. / 2. If I had listened to my friend's advice, I wouldn't have made that mistake.
