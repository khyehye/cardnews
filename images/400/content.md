## 📖 Writing Pattern Note
**1. 전환 공식**<br>문장 종류(긍정/부정/의문) → some 또는 any 결정 → 명사 앞에 삽입
**2. 단계별 순서**<br>① 문장이 긍정문인지 부정문인지 의문문인지 먼저 확인한다<br>② 긍정문이면 some, 부정문·의문문이면 any를 고른다<br>③ 권유·제안을 나타내는 의문문(Would you like ~?, Can I have ~?)은 예외로 some을 쓴다
**3. 자주 틀리는 포인트**<br>부정문 앞에 있는 not이나 don't/doesn't를 놓치고 무조건 some을 쓰는 실수가 가장 많다. 반대로 권유 의문문에서 any를 써서 어색해지는 경우도 흔하다.
**4. 대표 예문 (기본형 → 전환형)**
- I have some cookies. → I don't have any cookies. (긍정→부정)
- He has some free time. → Does he have any free time? (평서→의문)
- Do you want some water? (권유 의문문은 그대로 some 유지)
**5. 서술형 채점 포인트**<br>빈칸에 any를 써야 하는 부정문에서 some을 쓰면 감점 대상이다. 권유 의문문에서 any로 잘못 고치는 것도 자주 나오는 감점 사례이므로, 채점 시 문장 유형과 의도(권유인지 단순 질문인지)를 함께 확인해야 한다.

## ✏️ Practice
**A. Choose the correct word**
1. I don't have (some / any) questions.
2. Would you like (some / any) dessert?
3. Does she need (some / any) help?
**B. Fix the mistake**
1. He doesn't have some money. →
2. Do you have some brothers or sisters? →
3. I want some more time, please. (문맥상 부정문으로 바꿔보기: I don't want ___ more time.)
**C. Make your own sentence**<br>some과 any를 각각 하나씩 사용해 자기소개 문장 두 개를 만들어보세요. (예: 좋아하는 것에 대해 긍정문 하나, 없는 것에 대해 부정문 하나)

## ✅ Answer Key
**A.** 1. any 2. some 3. any
**B.**
1. He doesn't have any money.
2. Do you have any brothers or sisters?
3. I don't want any more time.
**C.** (자유 응답 — some은 긍정문에, any는 부정문/의문문에 정확히 쓰였는지 확인)
