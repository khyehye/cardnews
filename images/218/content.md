## 📖 Exam Trap Note

**1. 함정 포인트**
가정법 과거는 If절에 과거동사, 주절에 would/could/might + 동사원형을 쓰는 구조인데, 학생들은 be동사 자리에 was를 쓰거나 if절에 would를 넣는 실수를 자주 합니다.

**2. 판별 공식/체크리스트**

- If절 동사가 be동사인가? → 인칭 상관없이 were인지 확인
- If절 안에 would/could/might가 들어있지 않은가?
- If가 생략된 도치 구문(Were + 주어)인지 확인

**3. 오답 예문 vs 정답 예문**

- 오답: If I was taller, I would join the team.
- 정답: If I were taller, I would join the team.
- 오답: If she would know the truth, she would tell us.
- 정답: If she knew the truth, she would tell us.

**4. 기출 변형 패턴**

- If it were not for + 명사 (~가 없다면)
- Were + 주어 + to 동사원형 (도치, 미래에 대한 강한 가정)
- 콤마 뒤 주절의 조동사 선택(would/could/might) 뉘앙스 구별

**5. 실전 풀이 순서**
① If절 동사 확인 → be동사면 were인지 체크
② if절 안에 would 유무 확인 → 있으면 오류
③ 주절 조동사 + 동사원형 형태 확인

## ✏️ Practice

**A. 어법상 틀린 것 고르기**

1. If I ① was ② rich, I ③ would ④ travel the world.
2. If it ① were ② not for your help, we ③ would have ④ failed.
3. If she ① knew ② the truth, she ③ would ④ tells us.

**B. Fix the mistake (틀린 이유 서술)**

1. If he was younger, he would join the army. → 오류 이유를 서술하시오.
2. If I would have more time, I would visit you. → 오류 이유를 서술하시오.

**C. 유사 유형 만들어보기**
가정법 과거를 활용해 "만약 내가 새라면 ~할 텐데"라는 의미의 문장을 직접 만들어 보세요. (be동사 형태에 유의)

---

## ✅ Answer Key

**A.**

1. ① was → were (가정법 과거 be동사는 인칭 무관 were)
2. 정답 없음 (모두 올바름) — 함정 확인용 문제
3. ④ tells → tell (주절은 would + 동사원형)

**B.**

1. was는 가정법 과거에서 항상 were로 써야 함 (인칭 관계없이).
2. if절 안에 would를 쓸 수 없음 → If I had more time으로 고쳐야 함.

**C.** (예시) If I were a bird, I would fly to you. — be동사가 were로 정확히 쓰였는지 확인.
