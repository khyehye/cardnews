## 📖 Phrasal Verb Note
**1. 기본 의미 vs 관용적 의미**
- 기본 의미: 여행이나 이동을 시작하다 (물리적 출발)
- 관용적 의미: 경보, 반응, 사건 등을 촉발시키다
**2. 문형(분리형 여부)**
- set off는 목적어를 취하지 않는 자동사적 용법(출발)과, 목적어를 취하는 타동사적 용법(유발) 두 가지가 있다.
- 타동사 용법은 분리 가능(separable)하지 않은 편으로, "set + 목적어 + off" 형태보다는 "set off + 목적어" 어순이 훨씬 자연스럽다.
**3. 언제 쓰나요(뉘앙스·격식도)**
- 출발의 의미는 일상 회화와 여행 서술에서 흔히 쓰인다.
- 유발의 의미는 뉴스 기사, 학술 지문, 수능 독해의 격식체 문장에서 특히 자주 등장한다.
**4. 대표 예문**
- We set off before sunrise to beat the traffic.
- The announcement set off a wave of speculation in the markets.
**5. 헷갈리는 유사 구동사**
- set out: 목표를 갖고 의식적으로 무언가를 시작할 때 (더 formal, 의도성 강조)
- go off: 알람·폭탄 등이 "울리다/터지다"에 가까운 자동사 표현 (유발보다는 결과 자체에 초점)
- trigger: set off와 의미가 겹치지만 더 격식 있는 단일 동사
**6. 시험/회화 포인트**
- 수능 독해에서는 "사물 주어 + set off + 추상명사(chain of events, wave of, debate 등)" 패턴으로 자주 출제된다.
- 회화에서는 "set off on a trip/journey" 형태로 자주 쓰인다는 것도 함께 기억할 것.

## ✏️ Practice
**A. Choose the correct phrasal verb**
1. The rumor quickly ___ a wave of panic among investors.<br>(a) set off (b) set up (c) set aside
2. We plan to ___ for the coast as soon as the sun rises.<br>(a) set off (b) set down (c) set back
**B. Fix the mistake (전치사/어순 오류)**
1. The company set off the plan in motion last year. → (수정하세요)
2. She set the off alarm by accident. → (수정하세요)
**C. Make your own sentence**
- 사물 주어를 이용해 '유발하다'의 의미로 한 문장을 만들어 보세요.
- 사람 주어를 이용해 '출발하다'의 의미로 한 문장을 만들어 보세요.

## ✅ Answer Key
**A.**
1. (a) set off — "촉발시키다"의 의미, "set up"은 설립하다, "set aside"는 제쳐두다이므로 오답.
2. (a) set off — "출발하다"의 의미. "set down"은 내려놓다, "set back"은 지연시키다.
**B.**
1. → The company **set the plan in motion** last year. (set off는 이 문맥에 맞지 않음 — "set in motion"이 올바른 표현)
2. → She **set off the alarm** by accident. (분리해서 "set the off alarm"이라고 쓰면 안 되며, off는 목적어 앞에 위치)
**C.**
- 예시 답안: The scandal set off a wave of resignations across the company. / They set off for the mountains early Saturday morning.
