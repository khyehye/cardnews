## 📖 Grammar Note

### 1. 핵심 개념

가정법 과거는 시제가 과거일 뿐, 의미는 항상 "현재"를 가리킨다. 즉 "지금 그렇지 않은데, 만약 그렇다면"이라는 상상을 말할 때 쓴다. 일반 조건문(가정법 현재)과 달리, 실현 가능성이 거의 없거나 사실과 반대되는 상황에 쓴다는 점이 핵심이다.

### 2. 형태 / 공식

- If + 주어 + 과거동사 ~, 주어 + would/could/might + 동사원형 ~
- be동사는 인칭에 관계없이 were 사용 (구어체에서는 was도 종종 쓰이지만 문어체·시험에서는 were가 원칙)
- 주절에는 would 외에도 could(할 수 있을 텐데), might(할지도 모를 텐데)도 자주 쓰임

### 3. 언제 쓰나요?

현재 이룰 수 없는 소망이나 상상을 말할 때 사용한다. "돈이 많으면 좋겠다", "네가 나라면" 같은, 실현 가능성이 낮은 가정을 표현할 때 주로 쓰인다.

### 4. 대표 예문

- If I had more time, I would learn the guitar. (시간이 더 있다면, 기타를 배울 텐데.)
- If he were taller, he could be a model. (그가 더 크다면, 모델이 될 수 있을 텐데.)
- If we lived closer, we would meet more often. (우리가 더 가까이 산다면, 더 자주 만날 텐데.)
- If I were you, I wouldn't say that. (내가 너라면, 그렇게 말하지 않을 텐데.)

### 5. 자주 하는 실수

- X: If I will have money, I would buy a car. → O: If I had money, I would buy a car. (if절에 will 사용 금지)
- X: If I was a superhero, I would save the world. → O: If I were a superhero, I would save the world. (가정법의 be동사는 were)
- X: If she studied harder, she will pass. → O: If she studied harder, she would pass. (주절 시제 일치)

### 6. 시험 포인트

빈칸에 동사를 과거형으로 바꾸는 문제, was/were 중 올바른 것을 고르는 문제, 그리고 가정법 과거를 직설법(사실 진술)으로 바꿔 쓰는 문제가 자주 출제된다. "If I were you" 같은 관용 표현도 단독으로 자주 출제된다.

## ✏️ Practice

### A. Choose the correct answer

1. If I ___ a millionaire, I would buy a big house. (a. am / b. were / c. will be)
2. If she ___ the answer, she would tell you. (a. knows / b. knew / c. will know)
3. If it ___ sunny tomorrow, we would go on a picnic. (a. is / b. were / c. will be)
4. If they ___ harder, they would win the game. (a. try / b. tried / c. will try)

### B. Fix the mistake

1. If I was a bird, I would fly away. →
2. If he studies more, he would get a better grade. →
3. If we will have a car, we would travel more. →

### C. Make your own sentence

1. "If I were rich, ~"로 시작하는 문장을 완성해보세요.
2. 지금 갖고 싶은 능력이나 물건을 가정법 과거로 표현해보세요.

## ✅ Answer Key

A. 1. b (were) — be동사는 가정법에서 인칭 상관없이 were / 2. b (knew) — if절은 과거형 / 3. b (were) — 가정법 be동사는 were / 4. b (tried) — if절은 과거형
B. 1. If I were a bird, I would fly away. / 2. If he studied more, he would get a better grade. / 3. If we had a car, we would travel more.
C. 1. If I were rich, I would travel around the world. / 2. If I could speak five languages, I would work abroad.
