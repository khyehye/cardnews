## 📖 Writing Pattern Note
**1. 전환 공식**<br>[문장 A] + [문장 B (it/they = A의 명사)] → [문장 A] + which + [문장 B의 나머지]
**2. 단계별 순서**<br>① 두 문장에서 공통으로 가리키는 명사를 찾는다<br>② 뒷문장의 대명사(it/they)를 which로 바꾼다<br>③ which절을 앞문장의 해당 명사 뒤로 옮겨 붙인다
**3. 자주 틀리는 포인트**
- which를 쓰고 나서 it/they를 또 남겨 대명사가 중복되는 실수
- 선행사가 사람인데 which를 쓰는 실수 (이때는 who)
- 콤마 유무를 구분하지 않고 써서 의미가 어색해지는 경우
**4. 대표 예문 (기본형 → 전환형)**
- I read the book. + It was boring. → I read the book which was boring.
- This is my car, which I bought last year.
**5. 서술형 채점 포인트 (감점 요인)**
- which 뒤에 대명사 중복 → 감점
- 관계대명사 생략 불가 자리(주격 관계대명사)에서 생략 → 감점
- 콤마 필요한 계속적 용법 문장에서 콤마 누락 → 감점

## ✏️ Practice
**A. Transform the sentence**
1. He wrote a novel. It became a bestseller. →
2. We visited a museum. It had dinosaur fossils. →
3. I lost my umbrella. It was brand new. →
**B. Fix the mistake**
1. I read the article which it explained the news well.
2. She bought a dress who was too small.
**C. Write your own**<br>좋아하는 물건이나 장소 하나를 골라, which를 사용해서 두 문장을 한 문장으로 합쳐 보세요.

## ✅ Answer Key
**A.**
1. He wrote a novel which became a bestseller.
2. We visited a museum which had dinosaur fossils.
3. I lost my umbrella, which was brand new.
**B.**
1. I read the article which explained the news well. (it 삭제)
2. She bought a dress which was too small. (who → which)
**C.** 자유 작문 — which 뒤에 대명사가 중복되지 않았는지 확인
