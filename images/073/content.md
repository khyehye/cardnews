## 📖 Grammar Note

### 1. 핵심 개념

일반 가정법 과거완료는 if절과 주절이 모두 과거의 일을 다루지만, 혼합가정법은 두 절의 '시점'이 서로 다르다. 과거에 있었던(혹은 없었던) 일이 현재까지 영향을 미치거나, 반대로 현재 상황이 과거의 특정 순간에 영향을 미쳤을 것이라고 상상할 때 사용한다.

### 2. 형태 / 공식

- Type 1 (과거 조건 → 현재 결과): If + 주어 + had + p.p., 주어 + would(could/might) + 동사원형
- Type 2 (현재 조건 → 과거 결과): If + 주어 + were/동사의 과거형, 주어 + would(could/might) + have + p.p.
- 부정문에서는 각각 hadn't / weren't 등을 사용

### 3. 언제 쓰나요?

과거의 선택이나 사건이 지금까지도 영향을 주고 있다는 걸 강조하고 싶을 때 Type 1을 쓴다. 반대로 지금의 성격, 상태, 상황이 과거 어느 시점의 결과를 바꿨을 거라고 말하고 싶을 때는 Type 2를 쓴다. 실제 회화에서는 Type 1이 훨씬 자주 등장한다.

### 4. 대표 예문

- If I had saved money in my twenties, I would be financially free now. (20대에 돈을 모았다면, 지금 경제적으로 자유로울 텐데.)
- If he hadn't quit the team, he would still be playing today. (그가 팀을 그만두지 않았다면, 오늘도 여전히 뛰고 있을 텐데.)
- If we hadn't missed the flight, we would be in Paris right now. (비행기를 놓치지 않았다면, 지금 파리에 있을 텐데.)
- If she weren't so shy, she would have spoken up at yesterday's meeting. (그녀가 그렇게 수줍지 않다면, 어제 회의에서 말했을 텐데.)
- If I didn't have work today, I would have joined the trip last weekend. (오늘 일이 없었다면, 지난 주말 여행에 함께 갔을 텐데.)

### 5. 자주 하는 실수

- X: If I have studied medicine, I would be a doctor now. → O: If I had studied medicine, I would be a doctor now.
- X: If she wasn't busy now, she would helped us yesterday. → O: If she weren't busy now, she would have helped us yesterday.
- X: If I had been rich, I will travel the world now. → O: If I had been rich, I would travel the world now.

### 6. 시험 포인트

혼합가정법은 주로 밑줄 오류 찾기 문제로 출제되며, if절과 주절의 시제를 똑같이 맞춰버리는 실수를 유도하는 함정이 자주 나온다. 문장에 "now", "today" 같은 현재 시간부사가 있는지 확인하면 Type 1인지 판단하는 데 큰 힌트가 된다.

a) would join b) would have joined c) join d) had joined
