## 📖 Exam Trap Note
**1. 함정 포인트**<br>조동사 뒤에 동사가 원형이 아닌 3인칭 단수형(-(e)s), 과거형(-ed), 동명사(-ing), to부정사(to+V)로 변형되어 나오는 것이 가장 흔한 오류 지점이다.
**2. 판별 공식/체크리스트**
- 조동사(can/could/will/would/may/might/must/should/shall) 뒤 → 동사원형(V) 확인
- 뒤에 -s, -ed, -ing가 붙어 있는가? → 있으면 오답
- to가 붙어 있는가? (must to, should to 등) → 있으면 오답
- 수동태 구조인가? → 조동사 + be(원형) + p.p. 형태인지 확인
**3. 오답 예문 vs 정답 예문**
- 오답: She can *sings* the song. / 정답: She can **sing** the song.
- 오답: He must *to finish* the work. / 정답: He must **finish** the work.
- 오답: They should *arrived* early. / 정답: They should **arrive** early.
**4. 기출 변형 패턴**
- 조동사 + not + 동사원형 (부정문에서도 원형 유지)
- 조동사 + be + p.p. (수동태, be가 원형으로 고정)
- 두 개의 동사가 and로 연결될 때 두 번째 동사도 원형 유지해야 함 (예: must stop and think)
**5. 실전 풀이 순서**<br>① 문장에서 조동사를 찾는다 → ② 바로 뒤 동사의 형태를 확인한다 → ③ -(e)s/-ed/-ing/to가 붙어 있으면 즉시 오답으로 표시한다 → ④ 수동태 여부를 확인해 be동사가 원형인지 점검한다

## ✏️ Practice
**A. Choose the correct word**
1. You must (return / returns) the book by tomorrow.
2. She will (call / calls) you after work.
3. The window should (be fixed / fixed) soon.
**B. Fix the mistake**
1. He can plays the guitar really well.
2. They must to leave before noon.
3. This report should submitted by Friday.
**C. Make your own sentence**<br>아래 조동사 중 하나를 골라 "조동사 + 동사원형" 구조의 문장을 직접 만들어보세요. (must / should / can)

## ✅ Answer Key
**A.**
1. return (조동사 뒤 동사원형)
2. call (조동사 뒤 동사원형)
3. be fixed (조동사+수동태, be는 원형)
**B.**
1. He can **play** the guitar really well. — 조동사 뒤 -s 불가, 원형 play로 수정
2. They must **leave** before noon. — 조동사 뒤 to 불가, to 삭제 후 원형
3. This report should **be submitted** by Friday. — 수동태 구조 누락, be 추가
**C.** (자유 작문 — 조동사+동사원형 구조 확인 후 채점)
