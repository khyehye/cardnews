## 📖 Confusion Note
**1. 각 단어 기본 뜻**
- so: 형용사/부사를 수식하는 부사(강조), 뒤에 명사가 오지 않음
- such: (a/an) + 형용사 + 명사 형태로 명사구 전체를 강조하는 한정사
**2. 구별 포인트 (판단기준 하나로 요약)**
- 뒤에 명사가 오는지만 확인한다. 명사가 있으면 such, 형용사/부사만 있으면 so.
- 예외: many, much 앞에서는 관용적으로 so를 그대로 쓴다 (so many, so much).
**3. 대표 예문 비교**
- so: The movie was so boring. (형용사만, 명사 없음)
- such: It was such a boring movie. (boring movie라는 명사구)
**4. 자주 하는 실수 (X→O)**
- X: It was so boring movie. → O: It was such a boring movie.
- X: She has such many books. → O: She has so many books.
- X: He is such kind. → O: He is so kind.
**5. 시험 포인트**
- 빈칸 뒤에 명사가 있는지 없는지를 확인하게 하는 문제가 자주 출제된다.
- many/much 앞에서는 so를 쓴다는 예외 규칙을 반드시 암기해야 한다.

## ✏️ Practice
**A. Choose the correct word**
1. The concert was ( so / such ) amazing that we stayed for the encore.
2. It was ( so / such ) an amazing concert.
3. I've never seen ( so / such ) much rain in one day.
**B. Fix the mistake**
1. It was so good movie.
2. She is such kind.
3. We had such many problems yesterday.
**C. Make your own sentence**
- so를 사용한 문장 만들기
- such를 사용한 문장 만들기 (a/an 포함)

## ✅ Answer Key
**A.**
1. so — amazing 뒤에 명사가 없음
2. such — an amazing concert, 명사구를 강조
3. so — much 앞에는 항상 so (예외 규칙)
**B.**
1. It was so good movie. → It was such a good movie. (good movie는 명사구이므로 such)
2. She is such kind. → She is so kind. (kind 뒤에 명사가 없음)
3. We had such many problems yesterday. → We had so many problems yesterday. (many 앞에는 so)
**C.** (자유 작문 — 학생 답안에 따라 개별 채점)
